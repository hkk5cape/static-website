STATUS: Source prepared; GitHub Pages deployment and live evidence are pending.
This reuses the static research page from the earlier eCommerce task. A reference to a Python example not included on this site has been removed.
Preview
Open index.html in a web browser. No virtual environment, Python server or npm installation is required. Keep styles.css beside index.html where present.
Deploy
Sign into GitHub and create a PUBLIC repository called StaticWebsite. Initialise it with a README.
Upload the contents of this folder, placing index.html at the repository root (not inside another folder). Include styles.css where present. Keep the README.
Commit to main. Under Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
Wait for deployment to succeed. Open the actual published URL shown in Pages settings. Check the deployed site, not the GitHub source-code page.
Replace the pending text in static_url.txt with that exact working HTTPS URL, as a single line.
Capture the deployed page with the browser address bar visible. Save the genuine screenshot as static_page.png. Do not rename a local preview to claim deployment.
Include the source files, static_url.txt, and static_page.png in your task submission folder, then request review on your bootcamp dashboard.
